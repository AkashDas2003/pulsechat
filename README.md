# PulseChat

A full-stack real-time chat application built from scratch with the 
**MERN stack** (MongoDB, Express, React, Node.js) and **Socket.IO**.

PulseChat goes beyond a basic messaging clone — it includes group chats, 
media sharing, message reactions, WebRTC voice/video calling, and 
AI-powered features like conversation summarization and semantic search, 
all backed by JWT authentication and a scalable Socket.IO real-time layer.

## Features
- 🔐 JWT-based authentication with hashed passwords
- 💬 Real-time 1-on-1 and group messaging (Socket.IO)
- 👀 Typing indicators, read receipts, online presence
- 📎 Media sharing (images, files, voice notes)
- 😄 Message reactions, replies, edit/delete
- 📹 Voice & video calling (WebRTC)
- 🤖 AI-powered chat summarization & semantic search
- 🌙 Dark mode, responsive design

## Tech Stack
**Frontend:** React (Vite), Tailwind CSS  
**Backend:** Node.js, Express, Socket.IO  
**Database:** MongoDB Atlas + Mongoose  
**Auth:** JWT, bcrypt  
**Media:** Cloudinary
